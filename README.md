# КУЗНЯ

> Движок для создания текстовых MU* на русском.

Данный движок создан с упором на быстроту и интуитивность разработки. Скриптовый язык: python. Редактируйте код и контролируйте сервер в одном процессе.

## Особенности
1) Редактор == Сервер - ведите разработку и модерацию из терминала, движок tui-first
2) Полностью настраиваемый веб-клиент
3) Легкие в освоении абстракции
4) Работа с ИИ-агентами: MCP-сервер, через который агент пишет скрипты, создает объекты и персонажей, запускает игру и сам ее проверяет - см. [AGENTS.md](AGENTS.md)
5) Ассеты: скрипты и объекты можно выгрузить в файл и загрузить в чужой проект

## Запуск проекта
### Установка вручную
1) **Скачайте официальный репозиторий и перейдите в него**
```bash
git clone https://github.com/DanielBash/kuznya.git
cd kuznya
```

2) **Установите зависимости и запустите среду разработки**
```bash
pip install -r requirements.txt
cd src
python main.py
```

## Игры на движке
- [Brockton Bay](games/worm/README.md) - онлайн-RPG по веб-сериалу Worm с симуляцией города: у каждого жителя есть работа, дела и характер, цены зависят от того, кто вышел на смену, а суперсилы достаются тем, кто едва выжил. Мир целиком собран через MCP-сервер.
