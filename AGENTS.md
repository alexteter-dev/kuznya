# ИИ-агенты и ассеты

Кузня умеет работать с ИИ-агентами: агент создает и правит скрипты, объекты, шаблоны и персонажей,
запускает игру, сам в нее играет и читает ошибки из логов сервера. Все это доступно тремя способами.

## 1. MCP-сервер без редактора

Подходит для Claude Code, Claude Desktop и любого другого клиента MCP. Зависимостей сверх `requirements.txt` нет.

```bash
python src/mcp_server.py games/my_game.wrld
```

Для Claude Code достаточно открыть папку репозитория: в ней лежит `.mcp.json`. Вручную:

```bash
claude mcp add kuznya -- python src/mcp_server.py
```

Файл мира можно не указывать: агент откроет или создаст его инструментами `world_open` и `world_new`.
Каждое изменение сразу сохраняется в файл.

## 2. MCP-сервер внутри редактора

Вкладки → ИИ-агенты → «Запустить MCP-сервер». Агент работает с тем же миром, что открыт в редакторе,
и его правки сразу видны во вкладках. Сохранение остается за вами (вкладка «Экспорт»).

```bash
claude mcp add --transport http kuznya http://127.0.0.1:1341/mcp
```

Сервер слушает только `127.0.0.1`. Не открывайте этот порт наружу: через него можно менять файлы мира
и запускать код.

## 3. Встроенный помощник

Если клиента MCP нет, с миром может работать Claude напрямую через API:

```bash
pip install anthropic
export ANTHROPIC_API_KEY=...
python src/assistant.py games/my_game.wrld "Добавь таверну с барменом, который здоровается с игроками"
```

Без запроса запускается диалог в терминале.

## Что умеет агент

| Группа | Инструменты |
|---|---|
| Справка | `engine_docs` - описание скриптового API, агент читает его первым |
| Мир | `world_info`, `world_open`, `world_new`, `world_save`, `server_settings`, `web_client_get`, `web_client_set` |
| Скрипты | `script_list`, `script_get`, `script_create`, `script_update`, `script_delete` |
| Объекты и шаблоны | `object_tree`, `object_get`, `object_find`, `object_create`, `object_create_many`, `object_update`, `object_move`, `object_copy`, `object_delete` |
| Персонажи | `character_create` - объект с описанием и характеристиками, либо шаблон игрока |
| Ассеты | `asset_export`, `asset_inspect`, `asset_import`, `asset_list` |
| Запуск и проверка | `server_start`, `server_stop`, `server_status`, `server_logs`, `play_connect`, `play_send`, `play_read`, `play_disconnect` |

На объект можно сослаться идентификатором, уникальным именем или путем из имен: `/Город/Порт/Пекарня`.
Шаблоны адресуются с приставкой `prefab:` - `prefab:/Игрок`.

Синтаксис скриптов проверяется до сохранения, поэтому сломанный скрипт в мир не попадет.

## Ассеты

Ассет - файл `.kasset` (обычный JSON) со скриптом или объектом, который можно отдать другому человеку.

- Ассет скрипта включает сам скрипт и все библиотеки, которые он подключает через `world.require`.
- Ассет объекта включает объект со всеми дочерними объектами и все скрипты, которые им нужны.

В редакторе: Вкладки → Ассеты. Укажите скрипт или объект, файл, и нажмите «Экспорт». Чтобы загрузить чужой
ассет, укажите путь или ссылку `http(s)://` и нажмите «Загрузить ассет»: скрипты появятся в списке скриптов,
объект - в шаблонах. «Загрузить в объект» кладет объект сразу в сцену.

При загрузке все идентификаторы выдаются заново, так что один ассет можно загружать сколько угодно раз.
Если скрипт с таким именем уже есть и его код отличается, существующий скрипт не трогается
(агент может выбрать `on_conflict`: `keep`, `replace` или `rename`).

Ассет содержит код, который будет выполняться на вашем сервере. Загружайте ассеты только из источников,
которым доверяете, либо сначала посмотрите содержимое (`asset_inspect` или любым текстовым редактором).

## Библиотеки скриптов

Любой скрипт можно подключить из другого скрипта как библиотеку:

```python
economy = world.require('Экономика')   # код скрипта выполняется один раз, self в нем равен None

@self.on_event('on_message')
def on_message(message):
    self.send(economy.price_of('хлеб'))
```

Общую логику и таблицы данных удобно держать в библиотеках, а к объектам прикреплять короткие скрипты.

## Проверка

```bash
pip install mcp
python tests/test_mcp.py
```

Тест поднимает MCP-сервер, официальным клиентом собирает мир, запускает игру, играет в нее и переносит
ассеты между двумя мирами.
